# Booking App

A small Go application for experimenting with booking-related backend functionality.

## Technology

The repository is a Go module with a lightweight application entry point.

## Getting Started

```bash
go run .
go build ./...
go test ./...
```

## Project Structure

The current project is intentionally small, with `main.go` providing the application entry point and `go.mod` defining the Go module.

## Development

Keep environment-specific configuration and credentials out of source control. Add tests as booking functionality grows.

## Purpose

This repository provides a minimal starting point for building and experimenting with a Go booking service.
